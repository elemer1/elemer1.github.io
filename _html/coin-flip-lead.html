抛硬币的领先悖论

一枚公平的硬币，两个人对赌 20,000 次。直觉说两人各领先一半时间。十万局模拟和一段只用组合计数的证明都说：不是这样。

先修正原文的三处说法，其余部分没问题。

① “绝大多数对局中，一方从头压制到尾”是错的。一方领先 ≥98.25% 时间的局只占 16.9%（每一方各 8.5%）；真正“从头到尾没平过”的只有 0.56%。准确的说法是：极端结果是单个取值里最可能的，均衡结果是最不可能的。分布是 U 形，但 U 的中间并非空的。

② “19,650 次的概率远大于各领先一半”成立，但它比较的是两个单点。P(甲恰好领先 19,650 步) ÷ P(恰好 10,000 步) = 3.81。换成区间比较更有力：一方领先 ≥98.25% 的概率是 16.9%，而同样宽度的中间区间（48.25%–51.75%）只有 2.2%，差 7.6 倍。

③ “公平”并没有被打破。甲领先时间的平均值恰好是 50%（模拟得 49.89%）。错的是把“平均 50%”当成“典型 50%”。

20,000 与 19,650 这组数字的原始出处我没有核实到；Feller《概率论及其应用》第一卷第三章确实讨论了这一现象（“反正弦律”），下面的推导沿用他的组合路线，但只用计数和归纳法。

对照组：同一批硬币，换一个问题

直觉并不是凭空来的。问“20,000 次里正面占多少”，答案确实紧贴 50%：标准差只有 0.35%。问“甲领先的时间占多少”，就成了 U 形。两张图用的是同样的随机硬币，只是统计的量不同。

二、离散数学推导

整段推导只用到：计数、二项式系数、一个一一对应（反射）、错项相消（telescoping）、数学归纳法。不出现极限、积分或测度。

2.1 记号

一局抛 $2n$ 次，$X_i=+1$（甲赢）或 $-1$（乙赢），$S_0=0,\ S_i=X_1+\cdots+X_i$。全部 $2^{2n}$ 条“路径”等可能，所以概率 = 符合条件的路径数 ÷ $2^{2n}$。

$N(m,x)$：从 0 出发走 $m$ 步到达 $x$ 的路径数。向上 $a$ 步、向下 $b$ 步，$a+b=m,\ a-b=x$，所以 $N(m,x)=\binom{m}{(m+x)/2}$（不是整数或越界时为 0）。

$u_{2m}=P(S_{2m}=0)=\dfrac{\binom{2m}{m}}{2^{2m}}$，约定 $u_0=1$。

$f_{2r}=P(\text{第一次回到 0 恰在第 } 2r \text{ 步})$。

$p_{2k,2n}=P(\text{在 } 2n \text{ 步中甲恰好领先 } 2k \text{ 步})$。

领先步数一定是偶数：相邻两次平局之间的一段路径起点和终点都是 0，长度必为偶数，且整段都在同一侧。

目标定理（离散反正弦律） $$p_{2k,2n}=u_{2k}\,u_{2n-2k},\qquad k=0,1,\dots,n.$$

2.2 引理 1：反射原理

引理 1设 $a,b>0$。从 $(s,a)$ 走到 $(t,b)$、途中碰到过 0 的路径，与从 $(s,-a)$ 走到 $(t,b)$ 的全部路径一样多。

给一条碰到过 0 的路径，找到它第一次碰 0 的时刻 $\tau$，把 $\tau$ 之前那一段上下翻转，得到一条从 $-a$ 出发到 $b$ 的路径。反过来，任何从 $-a$ 到 $b$ 的路径因为每步只走 ±1，必然经过 0；把第一次经过 0 之前的部分翻回去即可复原。这是一一对应。∎

2.3 引理 2：一直严格领先的路径数

引理 2$S_1,\dots,S_{2n}$ 全部 $>0$ 的路径有 $\binom{2n-1}{n}=\tfrac12\binom{2n}{n}$ 条，所以 $P(S_1>0,\dots,S_{2n}>0)=\tfrac12 u_{2n}$。

第一步必须向上，到达 $(1,1)$。设终点为 $2r$（$r=1,\dots,n$）。从 $(1,1)$ 到 $(2n,2r)$ 的路径共 $N(2n-1,2r-1)$ 条；其中碰过 0 的，按引理 1 等于从 $(1,-1)$ 出发的路径数 $N(2n-1,2r+1)$。于是

$$\#\{\text{始终}>0\}=\sum_{r=1}^{n}\bigl[N(2n-1,2r-1)-N(2n-1,2r+1)\bigr].$$

相邻项互相抵消，只剩首项减末项：$N(2n-1,1)-N(2n-1,2n+1)=\binom{2n-1}{n}-0$。又 $\binom{2n}{n}=\binom{2n-1}{n-1}+\binom{2n-1}{n}$，而这两项相等，所以 $\binom{2n-1}{n}=\tfrac12\binom{2n}{n}$。∎

2.4 三个推论

推论 A（从不平局）$P(S_1\ne0,\dots,S_{2n}\ne0)=u_{2n}$。

一直在上方和一直在下方对称，各为 $\tfrac12u_{2n}$，相加即可。∎

这一条本身就很反直觉：“$2n$ 步里一次都没平过”与“第 $2n$ 步恰好平局”概率完全相等。比如 20 次抛掷，两者都是 17.6%。

推论 B（从不落后）$P(S_1\ge0,\dots,S_{2n}\ge0)=u_{2n}$。

严格为正的路径 = 先向上走到 1，之后 $2n-1$ 步都不低于 1；整体下移 1，就是“$2n-1$ 步都 $\ge0$”的路径，所以后者也有 $\tfrac12\binom{2n}{n}$ 条。长度为奇数的这类路径终点是奇数，至少为 1，再走任意一步都不会跌破 0，所以长度 $2n$ 的“始终 $\ge0$”路径恰好是它的两倍：$\binom{2n}{n}$ 条。∎

推论 C（首次回到 0）$f_{2r}=u_{2r-2}-u_{2r}$。

“前 $2r-2$ 步没碰 0”这件事包含了“前 $2r$ 步没碰 0”，两者之差正是“第一次碰 0 恰在第 $2r$ 步”。代入推论 A。∎

2.5 引理 3：按首次平局分类

引理 3对 $m\ge1$：$u_{2m}=\sum_{r=1}^{m}f_{2r}\,u_{2m-2r}$。

把 $S_{2m}=0$ 的路径按“第一次回到 0 的时刻 $2r$”分类。前 $2r$ 步有 $f_{2r}2^{2r}$ 种走法，后 $2m-2r$ 步是一条独立的、终点为 0 的路径，有 $u_{2m-2r}2^{2m-2r}$ 种。相乘、求和、除以 $2^{2m}$。∎

2.6 定理的证明（对 $n$ 归纳）

边界 $k=n$。“$2n$ 步全归甲”等价于“$S_i\ge0$ 对所有 $i$”：若某个 $S_i=-1$，通向它的那一步两端都 $\le0$，归乙；反之若全部 $S_i\ge0$，每一步的两端都 $\ge0$ 且不能同为 0，于是至少一端 $>0$，归甲。由推论 B，$p_{2n,2n}=u_{2n}=u_{2n}u_0$。$k=0$ 对称。

中间 $1\le k\le n-1$。这时路径必定碰过 0（否则全部步数在同一侧，$k$ 只能是 0 或 $n$）。设第一次回到 0 在第 $2r$ 步。前 $2r$ 步整段在上方或整段在下方，两种情形各占 $\tfrac12 f_{2r}$。之后剩下 $2n-2r$ 步，是一条全新的路径：

  1. 若第一段在上方，甲已领先 $2r$ 步，剩下的路径里还需要甲领先 $2k-2r$ 步（要求 $r\le k$）；
  2. 若第一段在下方，剩下的路径里甲需要领先整整 $2k$ 步（要求 $r\le n-k$）。
$$p_{2k,2n}=\tfrac12\sum_{r=1}^{k}f_{2r}\,p_{2k-2r,\,2n-2r}+\tfrac12\sum_{r=1}^{n-k}f_{2r}\,p_{2k,\,2n-2r}.$$

右边的 $p$ 长度都小于 $2n$，按归纳假设代入 $p_{2j,2m}=u_{2j}u_{2m-2j}$：

$$p_{2k,2n}=\tfrac12\,u_{2n-2k}\underbrace{\sum_{r=1}^{k}f_{2r}u_{2k-2r}}_{=\,u_{2k}\ (\text{引理 3})}+\tfrac12\,u_{2k}\underbrace{\sum_{r=1}^{n-k}f_{2r}u_{2n-2k-2r}}_{=\,u_{2n-2k}\ (\text{引理 3})}=u_{2k}\,u_{2n-2k}.$$

∎

2.7 为什么是 U 形：相邻项之比

由 $\binom{2m}{m}$ 的定义直接得到 $\dfrac{u_{2m}}{u_{2m-2}}=\dfrac{2m-1}{2m}$，也就是 $u_{2m}=\prod_{j=1}^{m}\dfrac{2j-1}{2j}$。它严格递减：$1,\ \tfrac12,\ \tfrac38,\ \tfrac5{16},\dots$

于是

$$\frac{p_{2k+2,2n}}{p_{2k,2n}}=\frac{u_{2k+2}}{u_{2k}}\cdot\frac{u_{2n-2k-2}}{u_{2n-2k}}=\frac{(2k+1)(2n-2k)}{(2k+2)(2n-2k-1)}.$$

分母减分子，展开后只剩 $2n-4k-2$。所以当 $k<\tfrac{n-1}{2}$ 时比值 $<1$（在下降），过了中点之后 $>1$（在上升）。$p_{2k,2n}$ 从两端向中间严格单调下降，中点最小，两端最大。这就是 U 形，不需要任何近似。

2.8 把 19,650 对 10,000 算出来：Wallis 型夹逼

引理 4对 $m\ge1$：$\dfrac{1}{4m}\le u_{2m}^2<\dfrac{1}{2m+1}$。

上界。因为 $(2j-1)(2j+1)=4j^2-1<4j^2$，有 $\tfrac{2j-1}{2j}<\tfrac{2j}{2j+1}$。令 $v=\prod_{j=1}^{m}\tfrac{2j}{2j+1}$，则 $u_{2m}<v$，而 $u_{2m}\cdot v=\prod_{j=1}^{m}\tfrac{2j-1}{2j+1}=\tfrac13\cdot\tfrac35\cdots\tfrac{2m-1}{2m+1}=\tfrac{1}{2m+1}$（错项相消）。所以 $u_{2m}^2<u_{2m}v=\tfrac1{2m+1}$。

下界。对 $j\ge2$，$(2j-1)^2=4j^2-4j+1>2j(2j-2)$，所以 $\tfrac{2j-1}{2j}>\tfrac{2j-2}{2j-1}$。于是 $u_{2m}\ge\tfrac12\prod_{j=2}^{m}\tfrac{2j-2}{2j-1}$，两边乘以 $u_{2m}=\tfrac12\prod_{j=2}^{m}\tfrac{2j-1}{2j}$：$u_{2m}^2\ge\tfrac14\prod_{j=2}^{m}\tfrac{j-1}{j}=\tfrac1{4m}$。∎

换句话说，$u_{2m}$ 夹在 $\tfrac{1}{\sqrt{4m}}$ 和 $\tfrac{1}{\sqrt{2m+1}}$ 之间，大小“像 $1/\sqrt m$”。代入 $2n=20{,}000$：

$$\frac{p_{19650,\,20000}}{p_{10000,\,20000}}=\frac{u_{19650}\,u_{350}}{u_{10000}^2}\ \ge\ \frac{\sqrt{\tfrac{1}{4\cdot9825}\cdot\tfrac{1}{4\cdot175}}}{\tfrac{1}{10001}}=\frac{10001}{\sqrt{27{,}510{,}000}}\approx1.91.$$

这是一个严格证明：领先 19,650 步的概率至少是均分的 1.9 倍。直接把乘积算出来，精确比值是 3.81。原文的说法在单点比较的意义下成立。

2.9 附带一个更短的证明：最后一次平局

“最后一次平局发生在第 $2k$ 步” = “第 $2k$ 步平局” 且 “之后 $2n-2k$ 步不再平局”。后一段是独立的新路径，由推论 A：

$$P(\text{最后一次平局在 }2k)=u_{2k}\cdot u_{2n-2k}.$$

和领先时间是同一个分布。模拟里最后一次平局时刻的直方图同样是 U 形：最后一次平局落在前 5% 的局有 14.2%，落在正中间 45%–55% 的只有 6.4%。

3.2 领先权只在平局时换手，而平局少得惊人

甲要从领先变成落后，必须先经过 0。所以领先时间怎么分，完全取决于平局的次数和位置。

  • 20,000 次抛掷里，平局次数的期望是 $\sum_{m=1}^{10000}u_{2m}\approx111.8$ 次（模拟 112.1），不是几千次。
  • 其中约 78.8 次在前一半，只有 33.0 次在后一半。越往后，平局越稀。
  • 每次平局后领先权只有一半机会真的换边，所以整局平均只换手 56 次左右。

平局次数像 $\sqrt{n}$ 那样增长，而不是像 $n$。抛的次数翻 100 倍，平局只多约 10 倍。于是步数很多、换手很少，每次换手之间隔得很长。

3.3 “回本”为什么这么难：落后之后迟迟回不来

推论 A 说“$2n$ 步都没平过”的概率是 $u_{2n}$。换个说法：第一把输了之后，之后一直没能回本的概率也是 $u_{2n}$：

之后又抛了20 次200 次2,000 次20,000 次
仍未回本的概率 $u_{2n}$17.6%5.6%1.8%0.56%

次数乘 10，概率只除以约 3.2（$\sqrt{10}$）。这个衰减慢得反常：大多数人会很快回本，但总有相当比例的人要等极久。等待时间的平均值甚至是无穷大：由推论 C 和分部求和，$\sum_{r=1}^{n}2r\,f_{2r}=2\sum_{r=0}^{n-1}u_{2r}-2n\,u_{2n}$，再用引理 4 的夹逼可知它随 $n$ 无限增长（大致与 $\sqrt n$ 同阶）。这就是原文标题里的“回本陷阱”：游戏公平，却不保证你在任何合理的时间内回到起点。

3.4 一段超长的“远行”吃掉了大半局

一局可以切成若干段：从 0 出发、离开、再回到 0。每一段整段归一方。因为回到 0 的等待时间是上面那种“大多数很短、少数极长”的分布，最长的那一段往往比其余所有段加起来还长。模拟里，最长的一段平均占整局 62.5%（中位数 61.6%）。

于是领先时间占比基本由“那段最长的远行在哪一侧”决定。它在甲这边，甲的占比就被拉向 1；在乙那边就被拉向 0。一枚硬币决定了一个接近 0 或 1 的结果，这就是 U 形两端那么高的原因。

3.5 “平均 50%”和“通常 50%”是两回事

单看任意一步，甲在上方和下方的机会相等，所以领先占比的期望一定是 50%，公平性没有问题。直觉错在把 20,000 步当成了 20,000 次独立的抽签。正面次数确实是独立累加的，所以会稳稳集中到 50%（图 2a）。但“第 10,001 步是否领先”和“第 10,000 步是否领先”几乎总是同一个答案：它们共享了前 10,000 次抛掷的全部历史。20,000 个高度相关的量相加，不会互相抵消，而是整体一起偏向一边（图 2b）。

可以这样记：大数定律管的是“正面占比”，它会回到 50%；它不管“谁在领先”，领先者不会被拉回来。硬币没有记忆，不会因为甲领先了就偏向乙。甲已经积累的领先既不会被“纠正”，也没有外力把它拉回 0，只能靠运气慢慢被抹平，而那要等很久。

方法说明：精确值由 $u_{2k}u_{2n-2k}$ 逐项求和得到（双精度），全部 10,001 项之和为 1（误差 <10⁻¹²）；小规模表格由穷举全部路径得到，与公式逐项一致。模拟：numpy，10 万局 × 20,000 步。
